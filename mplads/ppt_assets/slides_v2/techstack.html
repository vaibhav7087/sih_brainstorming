Technology
Technology Stack & Implementation Pipeline
Core Technology Stack
🌐
Frontend — Next.js 15 + TypeScript
shadcn/ui component library, Tailwind CSS v4 for styling, Recharts for data visualization, Framer Motion for animations, React-Leaflet for GIS heatmaps. Server-side rendering for fast initial loads.
⚙
Backend — FastAPI (Python 3.11+)
Async request handling with automatic OpenAPI documentation. Pydantic models for strict input validation. JWT authentication with role-based access control. SQLAlchemy ORM for database operations.
🤖
ML Core — XGBoost + Isolation Forest + SHAP
XGBoost supervised classifier trained on CAG audit findings. Isolation Forest for unsupervised zero-day anomaly detection. SHAP TreeExplainer for per-work explainability with waterfall charts.
🗃
Database — SQLite → PostgreSQL
SQLite with WAL mode for hackathon prototype. Migration path to PostgreSQL with connection pooling. Parquet feature store for ML training data. Redis for session cache and real-time alerts.
Data Sources & Verification
📚
Primary Data — 143,257 MPLADS Records
data.gov.in open dataset with complete work lifecycle. eSAKSHI portal scraping for real-time transaction tracking. 85 documented CAG fraud cases for supervised model training.
🛡
AI Verification — De-Fake + CLIP + Geotag
De-Fake model detects AI-generated/manipulated site photos. CLIP ViT-B/32 matches images to work descriptions (cosine > 0.7). EXIF GPS coordinates verified against 500m work radius.
📊
Visualization — Recharts + GIS Heatmaps
Interactive charts for fund utilization, risk distribution, and vendor analysis. React-Leaflet India map with state-wise anomaly coloring. Exportable audit reports in PDF format.
🚀
Deployment — Vercel + Railway (Rs. 0 Cost)
Vercel for Next.js frontend with automatic previews. Railway for FastAPI backend with persistent storage. Docker containerization for consistency. CI/CD via GitHub Actions.
