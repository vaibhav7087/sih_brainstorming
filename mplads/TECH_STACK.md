## 1. RECOMMENDED TECH STACK

### Frontend Stack
```
Framework:        Next.js 15 (App Router) + TypeScript
UI Library:       Tailwind CSS v4 + shadcn/ui
State Management: Zustand (simple) + React Query/TanStack Query (data fetching)
Charts:           Recharts (primary) + lightweight D3.js (complex viz)
Maps:             React-Leaflet + OpenStreetMap (free, no API key)
Forms:            React Hook Form + Zod validation
Icons:            Lucide React
Animations:       Framer Motion (optional, for polish)
```

### Backend Stack
```
Framework:        FastAPI (Python 3.11+) - BEST for ML integration
Auth:             Simple JWT (PyJWT) - no external service needed
Database:         SQLite (hackathon) → PostgreSQL (production)
ORM:              SQLAlchemy + Alembic (migrations)
Task Queue:       Celery + Redis (if needed, otherwise sync)
API Docs:         Auto-generated by FastAPI (Swagger UI)
```

### ML/AI Stack
```
Core ML:          scikit-learn (Isolation Forest, Random Forest, Gradient Boosting)
NLP:              Hugging Face Transformers (FinBERT for financial text)
Anomaly Detection: Isolation Forest + Local Outlier Factor + DBSCAN
Data Processing:  pandas, NumPy, SciPy
Explainability:   SHAP (SHapley Additive exPlanations)
Visualization:    Matplotlib, Seaborn (for ML plots)
```

### Deployment Stack
```
Frontend:         Vercel (free tier - unlimited deploys)
Backend:          Railway ($5/month free credit) OR Render (free tier with sleep)
Database:         SQLite (local) → Neon PostgreSQL (free tier for production)
CI/CD:            GitHub Actions (free for public repos)
```

## 5. ML MODELS FOR ANOMALY DETECTION

### Model 1: Isolation Forest (Primary - Unsupervised)
```python
from sklearn.ensemble import IsolationForest

# Best for: Detecting outlier transactions without labeled data
# Benchmark: Up to 94.6% precision reported in public procurement fraud studies (e.g., EU / World Bank procurement anomaly benchmarks)
model = IsolationForest(
    n_estimators=200,
    contamination=0.05,  # Expect 5% anomalies
    max_samples='auto',
    random_state=42
)
```
